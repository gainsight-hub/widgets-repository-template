# Widgets Repository Template — Moved

> **⚠️ This repository has moved and is no longer maintained here.**
>
> The Widgets Repository Template now lives at:
>
> **https://github.com/Gainsight-Central/widgets-repository-template**

All content that used to be in this repository (the build script, sample widgets, scripts, stylesheets, and documentation) has been removed from here. Please use the new repository instead.

## What you need to do

- **Starting a new project?** Clone or use the template from the new location: https://github.com/Gainsight-Central/widgets-repository-template
- **Already cloned or forked this repository?** Update your remote to point to the new location, or re-create your project from the new template:
  ```bash
  git remote set-url origin git@github.com:Gainsight-Central/widgets-repository-template.git
  ```
- **Have bookmarks, links, or documentation pointing here?** Please update them to the new URL.

## Issues and contributions

Please open issues and pull requests in the new repository. Anything submitted here will not be reviewed.
